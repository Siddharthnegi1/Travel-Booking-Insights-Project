# Travel Booking Insights & Revenue Dashboard

Data Analyst Project Report
1. Project Overview
This project focuses on analysing a travel booking dataset (6,000+ records) to uncover insights related to revenue, customer behaviour, booking trends, and business performance.
The objective was to:
•	Clean and standardize messy real-world data 
•	Using Pivot Table build an interactive dashboard in Excel 
•	Generate actionable business insights 

2. Dataset Description
The dataset contains 12 columns:
•	Booking ID 
•	Customer ID 
•	Destination 
•	Package Type 
•	Booking Date 
•	Booking Status 
•	Total Price 
•	Payment Method 
•	Duration (Days) 
•	Country 
•	Repeat Customer 
•	Booking Source 

Data Issues Found
•	Inconsistent text (Delhi / delhi / DELHI) 
•	Missing values (Total Price, Repeat Customer) 
•	Mixed date formats 
•	Duplicate records 
•	Country inconsistencies 

3. Data Cleaning Process
Applied Excel techniques:
•	Filled missing Total Price using column average 
•	Standardized text using TRIM() and PROPER() 
•	Replaced blank repeat customers with "Unknown" 
•	Removed inconsistencies in destination & country 
•	Counted repeat customers using COUNTIF() 

4. Key Metrics from Dashboard
•	Total Revenue: ₹16.88 Cr 
•	Total Customers: 6000 
•	Average Booking Price: ₹27,519 
•	Average Duration: 6 Days 
•	Repeat Customers: 2,097 (~35%) 

5. Insights & Analysis
 1. Destination Performance
•	Top revenue destinations: Mumbai, Jaipur, Agra 
•	Lower revenue destinations: Delhi, Goa 
Insight:
High-performing destinations are likely premium or high-demand tourist hubs.

2. Package Type Analysis
•	Honeymoon packages generate highest revenue 
•	Family packages underperform 
Insight:
Romantic/luxury travel is driving business more than group/family travel.

3. Payment Method Trends
•	Cash & UPI dominate transactions 
•	Debit cards are least used 
Insight:
Customers prefer fast & convenient payment methods

4. Booking Source Distribution
•	Website, Mobile App, Agent are almost equally split (~33% each) 
Insight:
No single dominant channel - good diversification
But also indicates lack of channel optimization

5. Monthly Booking Trends
•	Peak: August (highest bookings) 
•	Drop: October–November 
Insight:
Seasonality plays a major role (holiday & travel seasons)

6. Customer Behaviour
•	Repeat customers ≈ 35% 
Insight:
Moderate retention - room for loyalty improvement

6. Business Recommendations
1. Focus on High-Revenue Segments
•	Promote Honeymoon & Luxury packages 
•	Upsell premium experiences 

2. Improve Low-Performing Areas
•	Redesign Family packages (pricing, offers) 
•	Add discounts or bundles 

3. Optimize Payment Experience
•	Promote UPI incentives (cashback, discounts) 
•	Reduce friction in card payments 

4. Increase Customer Retention
•	Launch loyalty programs 
•	Offer discounts for repeat bookings 
•	Personalized offers 

5. Seasonal Strategy
•	Run campaigns before peak months (June–July) 
•	Offer discounts in low months (Oct–Nov)

The analysis highlights revenue drivers, customer trends, and optimization opportunities, making it valuable for data-driven decision-making in the travel industry
